# 📐 02_TEMPLATE (Templates & Examples)

> **What this folder does**: Stores **blank templates** and **examples demonstrating length/depth** referenced when writing advanced SVAP audit reports.
> **Why it was newly established (2026-08-20)**: After writing actual audit reports (e.g., `AUDIT_Godhead_Doctrine_20260818_gemini.md`, `_claude.md`), the template in `SVAP_GHQ.md` only had `[...]` bracket placeholders, causing sections like PART B (Exposition/Exegesis) to be entirely omitted or only very few claims to be addressed repeatedly. The format was correct, but this was the root cause of the condensed length.

## 📦 Contained Files

| File | Purpose |
|:---|:---|
| `SVAP_TEMPLATE.md` | Blank template. A version of the `SVAP_GHQ.md` PART A~D format with **coverage enforcement mechanisms** added. |
| `SVAP_EXAMPLE.md` | A **fully completed example** to visually confirm length and depth. Uses a theologically safe, hypothetical subject. |

## 🚨 Strict Rules for Using `SVAP_EXAMPLE.md`

> [!CAUTION]
> **Do not copy and paste the theological conclusions or arguments from this example directly into actual audits.**
> To avoid the exact contamination path warned against by the `CREED_Override.md` C-4 detailed guidelines and `SVAP_GHQ.md` E-17 (Self-Verification Against Appeals to Authority) — "if theological content is embedded in the example fields, AI inherits those conclusions without textual collation" — this example is used **exclusively to demonstrate length and formatting**. Actual audits must freshly collate against `KJV_1769.txt` and `TheScripture_ko_en_search.json` every time.
>
> For this reason, the example subject chosen is an **indisputable topic agreed upon by all orthodox denominations (whether Trinitarian or Godhead)** (e.g., the Swoon Theory). The conclusions of living doctrinal debates (e.g., Trinity vs. Godhead) that are actual targets of audit are not used as examples.
