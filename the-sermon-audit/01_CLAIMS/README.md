# 📋 01_CLAIMS

> **This folder stores the list of doctrinal claims extracted at GATE -1.**

## File Structure

One claim list file is generated per sermon.

- Naming Convention: `CLAIMS_[PreacherName]_[SermonTitle]_[Date].md`
- Example: `CLAIMS_JohnDoe_ColossiansExposition_20260628.md`

## Content Structure

```
| # | Timestamp | Claim Summary (Paraphrase) | Quoted Verse | Risk | BVCAP Deploy Status |
```

- **Claim Summary**: Recorded as AI paraphrased content, not the preacher's original text (Copyright protection)
- **Risk**: 🟢 Safe / 🟡 Verification Needed / 🔴 Immediate Verification
- **BVCAP Deploy Status**: Whether the claim has been deployed to GATE 0~5
