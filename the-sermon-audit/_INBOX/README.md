# 📥 _INBOX

> **This folder is where you input the sermon manuscripts targeted for verification.**

## Usage

1. Place the sermon manuscript (text, YouTube subtitles, etc.) to be verified into this folder.
2. Naming Convention: `[PreacherName]_[SermonTitle]_[Date].md` (e.g., `JohnDoe_ColossiansExposition_20260628.md`)
3. The SVAP engine processes it sequentially starting from GATE -1.

## ⚠️ Precautions

- **This folder is registered in `.gitignore` and is not committed to Git.**
- Be careful not to leak the original sermon texts externally, as they are subject to copyright protection.
- After verification is complete, delete the original from this folder or archive it separately.
