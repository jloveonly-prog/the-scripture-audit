# 📊 02_REPORT

> **This folder stores the final sermon audit reports of the SVAP engine.**

## File Structure

One final report is generated per sermon.

- Naming Convention: `AUDIT_[PreacherName]_[SermonTitle]_[Date].md`
- Example: `AUDIT_JohnDoe_ColossiansExposition_20260628.md`

## Report Structure

1. **Sermon Metadata** (Preacher, Date, Source, Topic Verse)
2. **Extracted Doctrinal Claims List** (Summary of GATE -1 results)
3. **BVCAP Verification Results per Claim** (GATE 0~5 verdicts)
4. **Comprehensive Judgment** (Doctrinal soundness grade of the entire sermon)
5. **Spiritual Lesson** (LESSON-6)
