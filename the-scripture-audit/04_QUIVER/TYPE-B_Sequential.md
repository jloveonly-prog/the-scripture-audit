# 🔬 SKILL-02: TYPE-B — Sequential Parallel Integration Pipeline of Events

> **When to Trigger**: When two authors (or two records by the same author) describe the same event differently.
> **Core Doubt**: "Are these two descriptions the exact same 1-second snapshot? Or are they different moments within the event?"

---

## Execution Steps

```
[STEP 1] Direct comparison of the two records in a table
  → | Record 1 (Verse) | Record 2 (Verse) | Surface Difference |
  → Must juxtapose the original KJV text.

[STEP 2] Discernment of "A single moment vs. Process"
  → Core Question: "Are the two records a 1-second snapshot, or a sequential flow of events?"
  → If there is movement of actors (characters), exchange of dialogue, or flow of time within the event → Judge as a process.

[STEP 3] Timeline Reconstruction
  → Write a Single Sequential Narrative that includes all details of both records without contradiction.
  → Format: [T1] Event detail → Record 1 describes this step / Record 2 describes that step

[STEP 4] Create 'Fusion Reading'
  → Piece together the texts of both records in order to write one complete narrative paragraph.
  → Specify in parentheses which verse corresponds to which step.

[STEP 5] Original Language Verification
  → Is there a reason the same word is used differently in the two verses? (Differences in case, article, preposition)
```

### TYPE-B-ψ: Psychological Temporal Differential

```
Trigger Condition: When the same person's behavior changes regarding the same event after time passes
Principle:      Shock/emotional state determines a person's behavior/speech,
                and as time passes and emotions change, behavior also changes
Difference from TYPE-B:
  TYPE-B   = Different reporters record different points in time (Reporter Variable)
  TYPE-B-ψ = Behavior changes due to the psychological state change of the same person (Emotion Variable)
```

**Application Examples:**
- Mark 16:8 (Shock/Fleeing/Silence) → Matt 28:8 (Calm/Joy/Delivery) = Same women, different psychological stages
- Peter's 3 denials (John 18) → 3 confessions (John 21) = Same person, psychological shift

**Discernment Trigger**: When the exact same person's behavior completely flips, prior to external environmental changes, first examine the **Psychological Temporal Differential**.

### TYPE-B-μ: Micro-Sequential State Change

```
Trigger Condition: When the posture/position of the same subject within the same scene changes in a short time
Principle:      Since each Gospel reporter captures a different "moment" of the scene,
                there exists a micro-temporal difference in seconds/minutes
Difference from TYPE-B:
  TYPE-B   = Temporal difference is in minutes/hours/days (Macroscopic)
  TYPE-B-μ = State change in seconds within the same scene (Microscopic)
```

**Application Examples:**
- Luke 24:4 "STOOD BY" (Appears standing) → Mark 16:5 "SITTING" (Speaks sitting)
- Greek Verification: ἐπέστησαν (Instant appearance/standing state) → καθήμενον (Present participle, sitting state upon encounter)

**Discernment Trigger**: When the posture/position of an angel/person in the same scene differs, prior to minute/hour TYPE-B, first examine the **second-unit TYPE-B-μ**.
