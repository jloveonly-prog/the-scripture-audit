# 🔀 SKILL-48: TYPE-AU — Structural Isomorphism
**"The thing that hath been, it is that which shall be" — Ecclesiastes 1:9 KJV**

> **When to Activate**: When two different events/characters show a surprisingly **identical structural pattern**.
> Whereas the existing TYPE-F is specialized for a **3-stage timeline typology** of "Type (Old Testament) → Reality (Jesus) → Succession (New Testament Character)",
> TYPE-AU exposes the **Structural Isomorphism** between two events regardless of the timeline direction.
> **Core Question**: *"If these two events operate on the same structure, what is the principle that God has repeated?"*

> [!IMPORTANT]
> **Do not confuse with TYPE-F:**
> - `TYPE-F` = **3-stage timeline parallel** of Type → Reality → Succession (Past → Future direction)
> - `TYPE-AU` = **Structural isomorphism** between two events (Regardless of timeline, 1:1 pattern correspondence)
> TYPE-F proves prophetic fulfillment / TYPE-AU discovers repeated theological principles.

---

## ⚙️ Activation Conditions

```
□ When two different events/characters show a surprisingly identical pattern
□ When each element of the pattern (Action, Essence, Result, Judgment) corresponds 1:1
□ When the timeline direction does not match to call one a "type" of the other
□ When the question "Why does God repeat the same pattern?" is raised
□ When it is necessary to prove that the structural repetition is a design, not a coincidence
```

---

## ⚙️ Execution Steps

```
[STEP 1] Parallel Extraction of Event Elements
  → Extract at least 4 comparable elements from the two events.
  → Table format:
  → | Pattern Element | Event A | Event B |
  → Mandatory elements: Action, Essence, Result, Judgment
  → Optional elements: Object, Motive, Timing, etc.

[STEP 2] Isomorphism Determination
  → Does each element correspond 1:1?
  → Correspondence ratio determination:
     2/4: Possibility of coincidental similarity → Isomorphism unconfirmed
     3/4: Structural isomorphism candidate → Proceed to STEP 3
     4/4: Structural isomorphism confirmed → Proceed to STEP 3~4

[STEP 3] Extraction of Design Meaning
  → "Why did God repeat the same structure?"
  → Repetition = Intentional Design = Existence of a Principle
  → Formulate the principle [P] into a single sentence.
  → Format: "P: If [Condition] → Then [Result]"

[STEP 4] Principle Declaration + Cross-Validation
  → Declare the principle [P].
  → Cross-validate whether the same principle operates in a 3rd event (Event C).
  → Cross-validation success → Principle IRONCLAD
  → Cross-validation failure → Principle PROBABLE
```

## 📌 Reference Case 1: Tree of Knowledge Parallel Structure — Fall of Adam ↔ Fall of the Sons

```
[STEP 1] Parallel Extraction:

  | Pattern Element | Fall of Adam | Fall of the Sons |
  |:---:|:---|:---|
  | Action | Became one body with Satan by eating the fruit of the tree of knowledge | Became one body with the daughters of men |
  | Essence | Became one (one body) with the forbidden | Became one (one body) with the fallen beings |
  | Result | Demoted from son of God → man | Demoted from ruler (king) → flesh |
  | Judgment | Death sentence ("thou shalt surely die") | Lifespan limited to 120 years |

[STEP 2] Isomorphism Determination:
  → 4/4 Perfect correspondence = Structural isomorphism confirmed ✅

[STEP 3] Principle Extraction:
  → P: "If one becomes one body with a forbidden/fallen being → Status is demoted"
  → This is God's design principle: The mixture of the holy and the unholy
    inevitably causes a demotion in the status of the holy side.

[STEP 4] Cross-Validation — 3rd Event:
  → Event C: Fall of Solomon (1 Kings 11:1-4)
     Action: Became one body with strange women
     Essence: Union with forbidden beings (gentile idolaters)
     Result: Weakening of the Davidic dynasty's sovereignty → Division of the kingdom
     Judgment: The kingdom is rent (1 Kings 11:11)
  → 4/4 correspondence → Principle P cross-validation success ✅
  → Principle IRONCLAD confirmed
```

## ⚠️ Precautions

```
□ Do not declare structural isomorphism with only 2/4 correspondence.
  → The similarity of 2 elements could be coincidental.
  → At least 3/4 correspondence is required.
□ Without cross-validation (STEP 4), the principle remains PROBABLE.
  → The same principle must operate in a 3rd event to be IRONCLAD.
□ TYPE-F and TYPE-AU can be activated simultaneously.
  → When Event A→B has a typological relationship (TYPE-F) and structural isomorphism (TYPE-AU) at the same time:
  → The combination of the two TYPEs maximizes the evidence of design.
□ Principle [P] must be formulated into a single sentence.
  → Complex principles cannot be understood by the reader.
  → Adhere to the "If X → Then Y" format.
```
