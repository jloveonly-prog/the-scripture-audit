# 🏹 TYPE-S: Shared Lexical Bridge

> **Alias**: Gezerah Shavah (גְּזֵרָה שָׁוָה)
> **Hebrew Tradition**: The 2nd rule of Hillel's 7 Rules of Interpretation — "Same word, same principle"
> **Core Philosophy**: If the same key word is used in two different verses, the meaning established in one verse also applies to the other.

> [!IMPORTANT]
> TYPE-S is different from TYPE-I (Frequency Counting).
> TYPE-I = **How many times** a word appears (Numerical symmetry/design)
> TYPE-S = **Where else** a word appears (Semantic cross-connection)
> TYPE-I counts the frequency, while TYPE-S connects the meaning.

---

## Trigger Conditions

```
Trigger TYPE-S in the following situations:
1. A key word/root is found in a verse where the interpretation is uncertain.
2. The exact same word is used with an established meaning in another verse.
3. There is a possibility that the lexical connection between the two verses forms a theological bridge.
```

---

## Execution Steps

```
[STEP 1] Keyword Isolation
  → Isolate the key verb/noun/adjective from the target verse into the original language (Hebrew/Greek).
  → Identify it based on the original language root, not the translation.

[STEP 2] Cross-Reference Search
  → Collect other verses across the entire Bible where the same original language word is used.
  → Prioritize verses by the same author, in the same context, or related to the same person.

[STEP 3] Anchor Verse Selection
  → Among the collected verses, select a verse where the meaning of the word is contextually established as the anchor.
  → The meaning in the anchor verse must be undisputable.

[STEP 4] Bridge Construction
  → Apply the established meaning of the anchor verse to the target verse being interpreted.
  → Verify if the applied result is contextually consistent.

[STEP 5] Counter-Attack Blocking
  → In response to the counter-argument "It's just the same word, not a meaning connection":
     a) Is it the same author? (Possibility of aligned authorial intent ↑)
     b) Is it related to the same person/event? (Contextual connection ↑)
     c) Do other TYPEs (N/P/G, etc.) independently support this connection? (Multiple verification)
```

## 📌 Reference Case: θέλω Lexical Connection — Confirming Peter's Martyrdom at Calvary

```
[Target for Interpretation] John 21:18 — "shall carry thee whither thou wouldest not (ὅπου οὐ θέλεις)"
  → Key words: θέλω (to want/will) + ὅπου (where/place)
  → Question: "Where" is the place Peter is carried to but does not want to go?

[STEP 1] Key word = θέλω (thélō, to want/will)

[STEP 2] Cross-Reference Search Results:
  → Matthew 26:39 — "not as I will (θέλω), but as thou wilt"
     The scene where Jesus "willed not" but submitted at Gethsemane.

[STEP 3] Anchor Verse = Matthew 26:39
  → The place Jesus did not will (θέλω) to go but went = Calvary/Golgotha (John 19:17)
  → This meaning is undisputedly established ✅

[STEP 4] Bridge Construction:
  → Jesus: θέλω (willed not) → Calvary
  → Peter: θέλω (willed not) → ??? 
  → + "Follow me" (John 21:19) = Same path
  → ??? = Calvary ✅

[STEP 5] Counter-Attack Blocking:
  a) Same author? → ✅ John knew Matthew's record of Gethsemane (he was present at Gethsemane).
  b) Same person? → ✅ Jesus-Peter relationship, same event chain (Gethsemane → Calvary → Resurrection → John 21).
  c) Other TYPEs' support? → ✅ TYPE-N (Exclusivity), TYPE-P (Reverse Logic), TYPE-G (ὅπου adverb of place).
  → Passed multiple verification → CONFIRMED ✅
```

## 💡 The Core Value of TYPE-S

```
Traditional Academia's Approach: Interpret Verse A independently → Choose one of several possibilities
TYPE-S Approach:                 Discover that the key word of Verse A is also used in Verse B
                                 → The meaning of the word is established in Verse B
                                 → Apply the established meaning to Verse A
                                 → The possibilities of interpretation converge to one
                                 = Eliminates uncertainty with a lexical bridge
```

## ⚠️ Precautions When Using TYPE-S

> [!WARNING]
> Refrain from applying TYPE-S in the following cases.

| ❌ Dangerous Application | ✅ Safe Application |
|:---|:---|
| The Hebrew/Greek roots are different, but the words are the same only in the translation | Apply only when the original root is identical |
| The word is the same, but its grammatical function is completely different (verb ↔ noun) | Use in the same part of speech and similar grammatical structure |
| There are no other TYPEs supporting the connection | At least one independent verification from TYPE-N/P/G, etc. |
| The meaning of the anchor verse itself is debatable | The meaning of the anchor verse is contextually established |
