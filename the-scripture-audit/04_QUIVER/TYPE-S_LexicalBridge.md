# 🏹 TYPE-S: Shared Lexical Bridge

> **Alias**: Gezerah Shavah (גְּזֵרָה שָׁוָה)
> **Hebrew Tradition**: The second of Hillel's Seven Rules of Interpretation — "The same word, the same principle"
> **Core Philosophy**: If the same key word is used in two different passages, the established meaning in one passage is applied to the other passage.

> [!IMPORTANT]
> TYPE-S differs from TYPE-I (Frequency Counting).
> TYPE-I = **How many times** a word appears (Numerical symmetry/design)
> TYPE-S = **Where else** a word appears (Semantic cross-connection)
> TYPE-I counts frequency, and TYPE-S connects meaning.

---

## Activation Conditions

```
Activate TYPE-S in the following situations:
1. A key word/root is found in a passage of uncertain interpretation.
2. That same word is used with an established meaning in another passage.
3. The lexical connection between the two passages has the potential to form a theological bridge.
```

---

## Execution Steps

```
[STEP 1] Keyword Isolation
  → Isolate the core verb/noun/adjective in the target passage into the original language (Hebrew/Greek).
  → Identify based on the original root, not the translation.

[STEP 2] Cross-Reference Search
  → Collect other passages where the same original word is used throughout the Scripture.
  → Specifically prioritize passages involving the same author, same context, and same person.

[STEP 3] Anchor Verse Selection
  → Among the collected passages, select as an anchor the passage where the meaning of the word is contextually established.
  → The meaning in the anchor verse must be indisputable.

[STEP 4] Bridge Construction
  → Apply the established meaning of the anchor verse to the target passage.
  → Verify if the applied result is contextually consistent.

[STEP 5] Counter-Attack Blocking
  → Against the objection "It is merely the same vocabulary, not a semantic connection":
     a) Is it the same author? (Possibility of matching authorial intent ↑)
     b) Is it related to the same person/event? (Contextual connection ↑)
     c) Do other TYPEs (N/P/G, etc.) independently support this connection? (Multiple verification)
```

## 📌 Reference Case: θέλω Lexical Connection — Peter's Calvary Martyrdom Confirmed

```
[Target Passage] John 21:18 — "shall carry thee whither thou wouldest not" (ὅπου οὐ θέλεις)
  → Core vocabulary: θέλω (will/wouldest) + ὅπου (whither/where)
  → Question: Where is the "place" Peter is carried to against his will?

[STEP 1] Core Vocabulary = θέλω (thélō, to will/wouldest)

[STEP 2] Cross-Reference Search Result:
  → Matt 26:39 — "not as I will (θέλω), but as thou wilt"
     The scene where Jesus "wouldest not" but obeyed in Gethsemane

[STEP 3] Anchor Verse = Matt 26:39
  → The place Jesus went where he "wouldest not" via θέλω = Calvary/Golgotha (John 19:17)
  → This meaning is indisputably established ✅

[STEP 4] Bridge Construction:
  → Jesus: θέλω (wouldest not) → Calvary
  → Peter: θέλω (wouldest not) → ???
  → + "Follow me" (John 21:19) = the same path
  → ??? = Calvary ✅

[STEP 5] Counter-Attack Blocking:
  a) Same author? → ✅ John knew Matthew's record of Gethsemane (He was together in Gethsemane)
  b) Same person? → ✅ Jesus-Peter relationship, same event chain (Gethsemane→Calvary→Resurrection→John 21)
  c) Support from other TYPEs? → ✅ TYPE-N (Exclusivity), TYPE-P (Reverse Logic), TYPE-G (ὅπου adverb of place)
  → Passed multiple verification → CONFIRMED ✅
```

## 💡 Core Value of TYPE-S

```
Traditional Academic Method: Independently interpret Passage A → Choose one of several possibilities
TYPE-S Method:             Discover the key word of Passage A is also used in Passage B
                     → The meaning of that word is established in Passage B
                     → Apply the established meaning to Passage A
                     → The possibilities of interpretation converge to one
                     = Uncertainty is removed by the lexical bridge
```

## ⚠️ Precautions When Using TYPE-S

> [!WARNING]
> Refrain from applying TYPE-S in the following cases.

| ❌ Dangerous Application | ✅ Safe Application |
|:---|:---|
| Different Hebrew/Greek roots but the same word only in translation | Apply only when the original root is identical |
| Same word but completely different grammatical function (Verb↔Noun) | Use in the same part of speech, similar grammatical structure |
| Total absence of other TYPEs supporting the connection | At least one independent verification from TYPE-N/P/G, etc. |
| The meaning of the anchor verse itself is debatable | The meaning of the anchor verse is contextually established |
| The root is the same but its semantic distinction is exclusive to Classical poetic language (Homer, etc.) and vanished in Koine (New Testament era) (Added 2026-07-24) | Verify that the distinction is actually alive in the contemporary Koine usage of the New Testament |
| The underlying language (Aramaic/Hebrew) behind the Greek wordplay lacks that distinction entirely in the original utterance (Added 2026-07-24) | Verify that the same distinction exists in the underlying language, or if verifying the underlying language is unnecessary to begin with |

> ⚠️ **Mandatory Prerequisite Procedure (2026-07-24)**: The last two items in the table above are formalized as the "Linguistic Kinship Self-Check" sub-protocol (G-CHK-9) in `TYPE-G_Grammar.md`. Before constructing a TYPE-S bridge based on original word pairs, one must pass STEP 1~5 of that protocol.
