```

  → Numerical anomaly detected → Initiate TYPE-A/C + ANCHOR collection
  → Expressional exclusivity detected → Immediately trigger TYPE-N (Exclusivity Exhaustive Survey)
  → Sequential conflict detected → DE-OVERLAP + TYPE-B
  → Verse attack detected → TYPE-G + TYPE-H

```
