# 🏹 SKILL-39: TYPE-AL — Equivocation Detection
**"Catch the fallacy of subtly shifting the same word to a different meaning"**

> **When it triggers**: When the opponent uses the same word with different meanings during an argument, causing confusion.
> Especially when shifting the definition of core terms like "explicitness", "evidence", or "tradition" depending on the context.
>
> **One-line definition**: *"Same word, different meaning — the moment that happens, the argument collapses."*

---

## Trigger Conditions
`
[General]
1. When the opponent shifts the definition of a core term during an argument.
   (e.g., "explicitness", "evidence", "tradition", "inspiration", "miracle", "salvation", etc.)
2. When the same word is used with meaning A when advantageous, and meaning B when disadvantageous.
3. When the foundation of the argument is shaken by the shift in term definitions.

[Typical Code] Trigger immediately upon detecting the following patterns:
  - The same word is used with different meanings in the first and second halves of the argument.
  - Claiming "That's different" while the logical structure remains identical.
  - The opponent applies a broad definition to advantageous cases and a narrow definition to disadvantageous cases.
`

## Execution Steps
`
[STEP 1] Identify the Problematic Word
  → Extract the core term repeatedly used in the argument.

[STEP 2] Meaning Analysis by Usage Context
  → What meaning does the same word have in each context of utterance?

[STEP 3] Detect the Point of Meaning Shift
  → Point out the exact location where the meaning was subtly changed.

[STEP 4] Dismissal Declaration
  → "This argument commits the fallacy of equivocation by using the same word with different meanings. It is dismissed."
`

## 📌 Reference Case: Definition Shift of "Explicitness"

| Point of Utterance | Definition of "Explicitness" | Purpose |
|:---|:---|:---:|
| Early stage of rebuttal | "Direct declaration in a single verse" | Dismiss the Calvary hypothesis |
| After presenting the Trinity counterexample | "Structural connections across multiple verses are also explicit" | Save the Trinity |
| When attacking the Calvary hypothesis again | "If there is no single verse declaration, it is not explicit" | Dismiss the Calvary hypothesis again |

> **TYPE-AL Verdict**: The definition of "explicitness" changed at least twice during the argument.
> This is the fallacy of equivocation. A consistent definition is required.
> When applying a consistent definition — the Calvary hypothesis falls under the category of explicitness with the identical structure as the Trinity. ✅
