# 🏹 SKILL-37: TYPE-AJ — Cumulative Case Argument
**"Not a single piece of evidence, but a convergence of multiple independent evidences establishes the conclusion"**

> **When it triggers**: When the opponent attacks individual evidences one by one, claiming "This alone is not enough."
> Acknowledging the weakness of a single piece of evidence, but declaring that the **simultaneous convergence of multiple independent evidences** is a stronger confirmation.
>
> **One-line definition**: *"Even if one evidence is weak, if 10 independent evidences point to the same conclusion, that is the truth."*

> [!NOTE]
> **Theoretical Foundation of COMBO Structure**: The COMBO trigger (S3, GN14, etc.) of BVCAP already operates as a cumulative case argument. TYPE-AJ officially names that principle as a weapon.

## Trigger Conditions
`
[General]
1. When the opponent attacks individual TYPE weapons one by one, saying "That alone is not enough."
2. When formalizing the logical basis of a COMBO trigger.
3. When proving "Simultaneous convergence of multiple independent evidences = Elimination of the possibility of coincidence."
4. When, even if a single evidence is weak, N or more independent evidences point to the same conclusion.

[Typical Code] Trigger immediately upon detecting one or more of the following sentences:
  - "That alone does not prove it."
  - "Each individual evidence can be refuted."
  - "[Individual TYPE] alone does not establish the conclusion."
  → At this time, present the multiple TYPE trigger evidences as an AJ cumulative case table.
`

## Execution Steps
`
[STEP 1] Independent Evidence Inventory
  → List the independent evidences pointing to the same conclusion.
  → Verify that each evidence is mutually independent.

[STEP 2] Convergence Point
  → Confirm the single conclusion that all independent evidences point to.

[STEP 3] Calculation of Coincidence Probability
  → The probability that N independent evidences simultaneously point to the same conclusion = extremely low.
  → ∴ It is a True Convergence, not a coincidence.

[STEP 4] Cumulative Verdict
  → "Each single piece of evidence can be attacked individually,
     but to reject all independent evidences simultaneously requires an equal number of refutations."
`
