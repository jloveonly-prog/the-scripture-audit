# 🔬 SKILL-01: TYPE-A — 연대기 직렬 분해 파이프라인

> **언제 발동하는가**: 두 본문의 숫자가 충돌하고, 기존 학계가 "두 기간이 겹친다"고 처리하는 경우.
> **핵심 의심**: "기간들이 정말 겹치는가? 아니면 순서대로 더하면 새로운 숫자가 나오는가?"

---

## 실행 단계

```
[STEP 1] 관련 구절 전체 수집
  → 충돌하는 두 구절 + 관련된 모든 구절(병행 본문, 족보, 왕의 재위년 등)을 빠짐없이 나열한다.
  → KJV 원문과 함께 각 구절에서 추출 가능한 모든 숫자(나이, 재위 기간, 사망 나이)를 리스트화한다.

[STEP 2] 타임라인 직렬 배치 (엑셀 방식)
  → 기간들을 '겹치는 것(Inclusive)'으로 보지 말고, 텍스트 서술 순서대로 '직렬(Sequential)'로 배치한다.
  → 표(Table)로 만든다: | 기간 | 시작 나이/연도 | 종료 나이/연도 | 성경 근거 |
  → 단, 텍스트에 명시적으로 "동시에" 혹은 "그 기간 중에"라는 표현이 없으면 무조건 직렬로 가정한다.
  → ⚠️ 예외(2026-09-09): "N년 통치하고 죽었다"류 **총계 정형구**가 하위 사건(투병·전쟁 등)을 감싸면, 그 하위 기간은
    총계 안에 포함된 것으로 두고 직렬로 덧붙이지 않는다. 직렬 합이 목표 숫자와 맞아떨어져도 독립 앵커(타국 동기화 등)로
    총량을 검산한 뒤에만 채택한다 (판례: [A+C+G+AC]_아하지야_22세vs42세_오므리왕조력 — 32+8+2=42 오류 사례).

[STEP 3] 미지수(X) 역산
  → 충돌하는 숫자를 직렬 배치로 더하면 숨겨진 전체 연수(X)가 나온다.
  → 이 X가 공격받는 두 번째 숫자(예: 42세)와 일치하는지 확인한다.

[STEP 4] 생물학적 정합 검증
  → 도출된 나이(X)가 당시 시대 기준으로 생물학적으로 가능한가?
  → 부자 관계, 결혼 나이, 동시대 다른 인물들의 수치와 교차 검증한다.

[STEP 5] 언어적 검증
  → KJV 원문의 전치사, 시제, 문법 구조가 직렬 해석을 지지하는가?
  → 히브리어/헬라어 원문의 어근과 의미 범위를 확인한다.
```

## 📌 레퍼런스 케이스: 아하지야 연대난제

> **2026-09-09 갱신**: 아래 예시는 STEP3에서 "42=여호람의 나이"로 잘못 역산했던 구버전을
> 대체함(재검증에서 CP-SAT INFEASIBLE 확인, 3년 부족). 확정 판례는
> `03_WAR_LOG(전투기록)/[A+C+G+AC]_아하지야_22세vs42세_오므리왕조력.md`,
> 전문은 `05_REPORT(전과보고서)/difficulties/REPORT_아하지야_22세vs42세_유력.md` 참고.

```
[수집 구절]: 왕하 8:26 (22세), 대하 22:2 (42세), 대하 21:5/21:20 (32세 즉위, 8년 통치),
             대하 21:18-19 (2년 투병 — 8년 재위 중 마지막 2년), 왕하 8:16/8:25/3:1 (이스라엘 요람 5년/12년/총12년)

[직렬 배치 — STEP2, TYPE-A]:
  | 기간           | 시작 | 종료 | 성경 근거              |
  |:--------------|:---:|:---:|:----------------------|
  | 여호람 즉위 나이  | 32세 | -   | 대하 21:5, 21:20 역산   |
  | 여호람 통치 기간  | 32세 | 40세 | 대하 21:5, 21:20 (8년) |
  | (투병 2년은 8년 **안**의 마지막 구간 — 8년 뒤에 추가하지 않는다) | 38세 | 40세 | 대하 21:18-19          |
  | 아하지야 즉위    | -   | 22세 | 왕하 8:26              |

[역산 — STEP3, 산수 벽]:
  32 + 8 = 40세 ← 여호람의 사망 나이 상한. **42가 아니다.**
  이스라엘 동기화(왕하 8:16 요람5년 즉위 → 8:25 요람12년, 최대 8년 창)도 정확히 이 40세와 일치.
  42세 사망을 성립시키려면 요람 15년까지 필요 → 요람 총 12년 재위(왕하 3:1)를 초과 → **CP-SAT INFEASIBLE(3년 부족)**.
  ⛔ 결론: TYPE-A의 직렬 산수는 "42=여호람의 나이"를 스스로 봉쇄한다. 42는 **다른 종류의 눈금**이어야 한다(→ TYPE-C로 이관).

[검증 — STEP4, 생물학적 정합]:
  42가 아하지야 본인의 문자적 나이라면, 막내아들(대하 21:17, 22:1)이 40세에 죽은
  부친보다 2살 위가 됨 → 생물학적으로 불가능 ❌ (TYPE-AC 역가설 대입으로 확정 봉쇄)

[검증 — STEP5, 언어적 검증]:
  KJV "Forty and two years old **was Ahaziah**" — 계사의 문법 주어는 대명사가 아니라
  고유명사 Ahaziah 본인(TYPE-G). 즉 42도 **아하지야에게 귀속된 숫자**이며,
  "부친의 나이를 아들에게 얹은 관계적 표현"이 아니다. → 42의 정체는 개인 나이가 아니라
  오므리 왕조 원년(아사 27년, 왕상 16:15-16)부터 아하지야 즉위(요람12년=아사력69년)까지의
  왕조 연대(69−27=42, TYPE-C)로 성경 내부 동기화만으로 재현됨.
```

**교훈**: STEP3에서 직렬 합산이 우연히 목표 숫자와 맞아떨어져도(32+8+2=42), 그 "+2"가
원문이 명시한 구간 배치(8년 **안**의 마지막 2년)와 다르게 임의로 덧붙인 것이면 반드시
CP-SAT 등으로 다른 앵커(여기서는 이스라엘 요람 재위창)와 교차 검증한다. TYPE-A 혼자 결론을
내지 않고, 산수가 막히면(STEP3 실패) TYPE-C(기능적 범주 분리)로 이관하는 것이 표준 절차다.
