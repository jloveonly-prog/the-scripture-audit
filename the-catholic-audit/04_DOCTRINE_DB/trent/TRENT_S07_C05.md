# TRENT-S07-C05 — Anathema if one saith baptism is not necessary for salvation

| Item | Description |
|:---|:---|
| **ID** | TRENT-S07-C05 |
| **Source** | Council of Trent (Concilium Tridentinum) |
| **Article** | Session 7, Decree on Baptism, Canon 5 |
| **Dogmatic Grade** | De Fide |
| **Anathema** | ✅ Yes |
| **Year** | 1547 |

## Original Text (Summary)
> "If any one saith, that baptism is free (ad libitum), that is, not necessary unto salvation; let him be anathema (anathema sit)."

## Latin Original
> "Si quis dixerit, baptismum liberum esse, hoc est non necessarium ad salutem: anathema sit."

## Tags
`Sacramental Theology`, `Baptism`, `Soteriology`, `de_fide`, `necessary`, `forbidden`

## Claims
1. Baptism is necessary for salvation (necessarium ad salutem).
2. Without baptism, one cannot attain salvation (as the ordinary means).
3. Baptism is not optional, but obligatory.
4. Whosoever denieth this doctrine is anathematized (anathema).

## Negates
1. The proposition that baptism is not necessary for salvation.
2. The proposition that baptism is optional (free).
3. The proposition that one can be saved by faith alone without baptism.
